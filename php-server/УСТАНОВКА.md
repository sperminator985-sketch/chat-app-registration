# Перенос чата «Общага» на свой хостинг

Всё, что нужно — обычный хостинг с PHP 7.4+ и базой MySQL.
Времени займёт примерно 15 минут.

---

## Шаг 1. Создайте базу MySQL

В панели хостинга найдите раздел «Базы данных» (или «MySQL») и создайте новую базу.
Запишите четыре значения, они понадобятся дальше:

- адрес сервера базы (обычно `localhost`)
- имя базы
- имя пользователя
- пароль

## Шаг 2. Впишите эти данные в файл config.php

Откройте `config.php` в блокноте и замените значения на свои:

```php
'db_host' => 'localhost',
'db_name' => 'ваша_база',
'db_user' => 'ваш_пользователь',
'db_pass' => 'ваш_пароль',

'base_url' => 'https://ваш-домен.ru/chat',
'install_key' => 'придумайте-пароль',
```

`base_url` — адрес папки, куда вы положите файлы (без слэша в конце).
`install_key` — любой пароль, он нужен один раз для установки.

## Шаг 3. Загрузите файлы на хостинг

Через файловый менеджер панели или по FTP загрузите папку целиком
в корень сайта под именем `chat`. Должно получиться так:

```
public_html/
  chat/
    api.php
    config.php
    db.php
    install.php
    .htaccess
    uploads/     ← создастся сама
```

## Шаг 4. Создайте таблицы

Откройте в браузере:

```
https://ваш-домен.ru/chat/install.php?key=ПАРОЛЬ_ИЗ_CONFIG
```

Должно появиться «Готово! Таблицы созданы.»
Если пишет про папку uploads — создайте её вручную и поставьте права 755.

**После этого удалите файл `install.php` с хостинга.**

## Шаг 5. Переключите сайт на свой сервер

В проекте сайта откройте файл `src/lib/api.ts` и в самом верху замените адрес:

```js
const API_URL = 'https://ваш-домен.ru/chat/api.php';
```

Опубликуйте сайт заново. Готово — чат работает на вашем хостинге без лимитов.

---

## Проверка, что всё работает

Откройте в браузере:

```
https://ваш-домен.ru/chat/api.php?action=feed&room=kurilka
```

Должен появиться текст вида `{"messages":[],"online":[],...}` — значит, сервер отвечает.

## Если что-то пошло не так

**Белая страница или ошибка 500** — скорее всего, неверные данные базы в `config.php`.
Проверьте имя базы, пользователя и пароль.

**«Ошибка на сервере чата»** — посмотрите файл логов ошибок в панели хостинга,
там будет строка, начинающаяся с `chat api:`.

**Аватарки не загружаются** — папке `uploads` нужны права на запись (755 или 777).

**Чат не видит сервер, в браузере ошибка CORS** — убедитесь, что сайт и чат
открываются по `https://`, а не по `http://`.

## Что перенеслось, а что изменилось

Работает так же: регистрация, вход, сообщения по девяти этажам, личные сообщения,
профиль с аватаркой, счётчики онлайна, звонки между жильцами.

Единственное отличие: аватарки теперь хранятся в папке `uploads` на вашем хостинге,
а не в облаке. Старые пользователи и переписка на новый сервер не переносятся —
чат начнёт с чистого листа. Если нужно перенести и их, скажите, подготовлю выгрузку.
